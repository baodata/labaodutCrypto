H-MARL-GNN — MASTER TICKET PLAN CHO NHÓM 2 NGƯỜI

Mục tiêu tài liệu

Tài liệu này là roadmap tổng thể để 2 thành viên phát triển đồ án
H-MARL-GNN theo đúng dependency. Mỗi ticket có owner chính, reviewer,
dependency và deliverable. Hai thành viên có thể đổi vai cho nhau, nhưng
nên giữ ownership module ổn định trong từng sprint.

Quy ước: - A = Data / Environment / Evaluation Lead - B = Graph / Model
/ RL Lead - P0 = bắt buộc - P1 = quan trọng - P2 = nâng cao - PASS = đạt
acceptance criteria - NEED CHANGES = chưa được merge/chuyển dependency

Ownership: A: src/data/ src/features/ src/env/ src/evaluation/

B: src/graph/ src/models/ src/agents/ src/training/

Shared: configs/ src/utils/ tests/integration/ scripts/ README.md

Nguyên tắc: 1. Không code trực tiếp lên main. 2. Mỗi ticket có branch
riêng. 3. Người viết ticket không tự approve PR của mình. 4. A code -> B
review; B code -> A review. 5. Không chuyển sang kiến trúc phức tạp
trước khi baseline đơn giản chạy đúng. 6. Financial split phải theo thời
gian; tránh look-ahead/data leakage. 7. Experiment phải lưu config, seed
và kết quả để tái lập.
