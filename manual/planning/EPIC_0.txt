[TASK 0.3] Cấu hình kiểm soát phiên bản (.gitignore)
--------------------------------------------------
Đảm bảo Git không bị phình to hoặc rò rỉ dữ liệu nhạy cảm:
- Môi trường ảo: `.venv/`, `venv/`, `env/`
- Bytecode Python: `__pycache__/`, `*.py[cod]`
- Dữ liệu tài chính: `data/raw/*`, `data/interim/*`, `data/processed/*`, `*.parquet`, `*.csv` (ngoại trừ .gitkeep)
- Checkpoints & Log: `experiments/*`, `runs/`, `*.pt`, `*.pth`
- File tạm của hệ điều hành & IDE: `.vscode/`, `.idea/`, `.DS_Store`
- Cache kiểm thử: `.pytest_cache/`


[TASK 0.4] Cấu hình cài đặt module nội bộ (pyproject.toml)
--------------------------------------------------
Tạo file `pyproject.toml` để biến thư mục `src/` thành một package có thể import được ở bất kỳ đâu thông qua lệnh:
    pip install -e .
Sau khi cài đặt, các script trong `tests/` hoặc `scripts/` có thể gọi:
    from src.data.downloader import download_market_data
    from src.env.portfolio import PortfolioState
mà không bao giờ bị lỗi `ModuleNotFoundError` hay phải dùng mẹo `sys.path.append()`.
