EPIC 2 — FEATURE ENGINEERING
======================================================================

TICKET FEAT-001 — Daily Return

Mục tiêu:
Tính:

r_t = (P_t - P_(t-1)) / P_(t-1)

File:
src/features/returns.py

Output:
Date
Close
Return

Test:
100 -> 102

Expected:
return = 0.02

Acceptance Criteria:
Unit test sai số < 1e-8.


----------------------------------------------------------------------
TICKET FEAT-002 — Rolling Volatility
----------------------------------------------------------------------

Mục tiêu:
Tính 20-day volatility.

Ví dụ:

returns.rolling(20).std()

Nếu annualized:

sigma_annual = sigma_daily * sqrt(252)

V1 chọn:
daily rolling volatility cho input model.

transform(test)

----------------------------------------------------------------------
TICKET ENV-002 — Portfolio Return Engine
----------------------------------------------------------------------

Input:
weights(t)
asset returns(t+1)

Tính:

R_p = SUM_i w_i * r_i

Unit test:

AAPL weight = 0.5
MSFT weight = 0.5

AAPL return = +10%
MSFT return = -10%

Expected:
portfolio return = 0%


----------------------------------------------------------------------
TICKET ENV-003 — Transaction Cost
----------------------------------------------------------------------

Implement:

Turnover_t = SUM_i |w_(i,t) - w_(i,t-1)|

TC_t = c * Turnover_t * V_t

Config:

transaction_cost_rate: 0.001

Không hard-code.


----------------------------------------------------------------------
TICKET ENV-004 — Drawdown Tracker
----------------------------------------------------------------------

Tính:
Peak(t)
Drawdown(t)
Maximum Drawdown

Formula:

DD_t = (V_t - Peak_t) / Peak_t


----------------------------------------------------------------------
TICKET ENV-005 — Risk Calculator
----------------------------------------------------------------------

V1 sử dụng rolling portfolio volatility.

Sau này có thể thêm covariance risk.


----------------------------------------------------------------------
TICKET ENV-006 — Reward Function V1
----------------------------------------------------------------------

Bắt đầu đơn giản:

Reward_t = R_portfolio,t - beta * TC_t

Sau khi model chạy ổn mới thêm:

- lambda * Risk_t

Không nhét quá nhiều penalty từ đầu.
